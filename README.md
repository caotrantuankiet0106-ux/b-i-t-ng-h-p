# Phần 2 – Mô hình IPO và lĩnh vực CNTT
Bảng mô hình IPO:

Input: Tín hiệu hình ảnh/âm thanh trận đấu từ màn hình.

Process: Phần mềm ghi hình xử lý, mã hóa và nén video.

Output: File video trận đấu hoàn chỉnh để xem lại.

Storage: Ổ cứng SSD lưu trữ file video.

Lĩnh vực CNTT: Mạng máy tính và truyền thông (đảm bảo internet phục vụ chơi game và livestream) và Kỹ thuật máy tính / Hệ thống thông tin (quản lý phần cứng và lưu trữ dữ liệu).

# Phần 4 – Phần cứng và mô hình DIKW
Nâng cấp linh kiện: Nâng cấp CPU. Cả chơi game nặng và livestream đều đòi hỏi CPU tính toán liên tục; nếu CPU quá tải máy sẽ bị giật, trong khi RAM 16 GB đã đủ đáp ứng.

Mô hình DIKW:

Data: Video thô ghi lại cảnh tuyển thủ bị hạ ở phút 15-20.

Information: Nhận ra tuyển thủ hay chết do thiếu tầm nhìn bản đồ.

Knowledge: Hiểu thiếu tầm nhìn dẫn đến bị mai phục và thua trận.

Wisdom: Ra quyết định mua thêm mắt (Ward) cho trận sau để khắc phục.
